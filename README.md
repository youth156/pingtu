# 电子拼图游戏 (Jigsaw Puzzle)

一款经典风格的电子拼图游戏，玩家可以选择自己的图片或使用预设图片，通过拖拽拼图块完成整幅图像的拼接。

## 功能特点

- 📁 **图片选择**：支持上传自定义图片或选择预设图片
- 🎮 **多种难度**：提供简单(3x3)、中等(4x4)、困难(5x5)三种难度级别
- 🎯 **拖拽操作**：直观的拖拽界面，支持平滑的拼图块移动
- 🎨 **视觉反馈**：拼图块悬停效果、放置正确时的动画反馈
- ⏱️ **游戏计时**：记录游戏时间和移动次数
- 💡 **提示功能**：提供位置提示帮助完成拼图
- 📱 **响应式设计**：适配不同屏幕尺寸
- 🎉 **完成统计**：游戏完成后显示详细统计信息

## 使用方法

1. 打开 `index.html` 文件即可开始游戏
2. 选择一张图片：
   - 点击「选择拼图图片」上传本地图片
   - 或点击下方预设图片直接使用
3. 选择难度级别（简单/中等/困难）
4. 点击「开始游戏」按钮
5. 从右侧拼图块区域拖拽拼图块到中央拼图板
6. 将拼图块放置在正确位置，完成整幅拼图
7. 游戏完成后会显示统计信息

## 游戏操作

- **拖拽拼图块**：点击并拖动拼图块到拼图板上
- **放置拼图块**：将拼图块靠近正确位置时会自动吸附
- **重置游戏**：点击「重置游戏」按钮重新开始
- **获取提示**：点击「提示」按钮显示随机拼图块的正确位置

## 技术实现

- **HTML5**：语义化标签构建页面结构
- **Tailwind CSS v3**：响应式样式和UI组件
- **JavaScript**：游戏逻辑、拖拽功能和交互效果
- **Font Awesome**：图标支持
- ** picsum.photos**：提供预设图片服务

## 自定义图片

您可以：
1. 直接通过上传功能使用本地图片
2. 将图片添加到 `images/` 文件夹中，然后在代码中引用

## 浏览器支持

- Firefox

- Edge

## 注意事项

- 为获得最佳体验，建议使用现代浏览器
- 大尺寸图片可能需要较长时间加载和处理
- 拼图难度越高，需要更多的时间和耐心完成

## 开发说明

如果您想进一步开发或自定义游戏：

1. 可以修改 `index.html` 中的 JavaScript 部分调整游戏参数
2. 添加更多预设图片到 `defaultImages` 数组
3. 自定义 CSS 样式改变游戏外观
4. 扩展游戏功能，如添加更多难度级别、保存游戏进度等
